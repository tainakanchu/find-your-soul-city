# 判断

[EVS/WVS](/sources/evs-wvs.md) 由来の価値観の近さは都市総合スコアに混ぜない。P1 では設問ごと除外する。

# 理由

国単位の調査を都市の住民属性とみなすことはできず、ステレオタイプ化のリスクがある（企画書 §4, §10）。外部検証の方法が決まってから別スコアとして設計する。
