# 使い方

方向型の指標は、都市の値がこの分布の何パーセンタイルにあたるか（分位点の間は線形補間、同値は中央の順位）を適合度 0〜1 とする。診断の対象都市ではなく世界の大都市圏全体を基準にするので、対象都市を増減してもほかの都市のスコアは変わらない。
