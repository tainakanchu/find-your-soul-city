# 総合スコア

都市 c・ユーザー u・軸 i について S(u,c) = 100 × Σ w_i f_i / Σ w_i。和は都市 c で欠損していない軸だけで取る。[^proposal]

# 適合関数 f_i

- **理想値型**（`kind: ideal`）: 変換後の値 t(v) と理想値 t(p) の差 d に対し f = exp(−½ (d/σ)²)。σ は各 [Metric](/metrics/) の `tolerance`。対象都市の選び方に依存しない。
- **方向型**（`higher_better` / `lower_better`）: [基準分布](/model/reference-distribution.md)（人口 100 万人以上の全都市圏 524）の中での百分位 F(t(v)) を f とする（少ないほど良い型は 1 − F）。分位点（5% 刻み）の間は線形補間、同値が続く区間は中央の順位。

# v0.1 からの変更（実データでの検証による）

v0.1 は方向型を「対象都市の 10〜90 パーセンタイルで線形、範囲外は 0/1 に張り付け」にしていた。実データで次の問題が出た（[検証結果](/reports/validation.md)）。

1. 上位 1 割の都市が同点の 1.0 に張り付き、方向型 5 指標のうち 4 つで満点のオスロが、無作為な回答の 21% で 1 位になった。
2. スケールが対象 86 都市に依存し、都市を追加・削除すると他の都市のスコアが動く。

百分位（基準分布）に変えることで張り付きがなくなり、対象都市を増減しても他都市のスコアは変わらない。

# 欠損と品質

- 欠損はゼロとして扱わない。その軸を外して重みを再正規化する。
- 重みの充足率（欠損していない軸の重み ÷ 全重み）が `min_coverage` 未満の都市は順位から外し、「データ不足」として件数を示す。
- 結果の品質ラベルは、使った軸のうち最も低いもの（imputed < estimated < observed）。補完値（imputed）は現在使っていない。
- 仮値（placeholder）は禁止。`knowledge:build` と本番ビルドの両方で検出したら失敗する（`src/model/guard.ts`）。

# 合う点・合わない点

- 合う点: f ≥ 0.6 の軸を w·f の大きい順に最大 3 つ。
- 合わない点: f < 0.5 の軸を w·(1−f) の大きい順に最大 2 つ。

# 頑健性

重みのある軸それぞれについて重みを ×0.9 / ×1.1 に変えて再計算し、1 位が変わらなかった割合を「安定度」として表示する。これは幸福や移住成功の確率ではない。

# 表示してよい主張

- 「回答と統計値が近い」「この指標の値は X」「基準分布の上位 Y%」のように、データとモデルから直接いえることだけを表示する。
- 住みやすさ・幸福度・移住の成否・住民の気質についての主張はしない。

# 決定論

同点は `city_id` の昇順。乱数は使わない（検証スクリプトは seed 固定）。同じ回答・同じデータ版・同じモデル版なら結果は一致する。
