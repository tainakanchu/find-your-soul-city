# 定義

- 期間: 2020 年

- 算出: GHS-UCDB の EM_PM2_CON_2020。上流は衛星と化学輸送モデルによる ACAG SatPM2.5 V6.GL.02.02 を人口加重で集計した値

# スコアへの入り方
