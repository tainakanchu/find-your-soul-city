# 定義

一年間の降水量の平年値。

- 期間: 1990–2019 年の平年値
- 範囲: 都市圏ポリゴン内の ERA5 陸セル（陸海マスク ≥ 0.5）の平均。セルがなければ最寄りの陸セル
- 算出: WB2 気候値の 24 時間降水量（4 時刻の平均）を mm/日に換算し、月の平均日数を掛けて合計

# スコアへの入り方

理想値型。ユーザーの理想値との差をガウス関数で 0〜1 にする（変換 `log10`、σ = 0.2）。

# 根拠と検証

対数で比較する（σ = 0.2 は約 1.6 倍の差）。観測所（201 都市圏）との比較で相関 0.84、比の中央値 1.06、±25% 以内が 70%。ボゴタ（×3.1）、キト（×2.0）、カトマンズ（×1.9）、サンティアゴ（×1.8）、ケープタウン（×1.6）、メキシコシティ（×1.5）、ムンバイ（×0.64）は欠損とした。

# 注意点

ERA5 は急峻な地形で降水を過大評価する。観測所との比が 1.5 倍を超えてずれる都市は欠損扱い。
