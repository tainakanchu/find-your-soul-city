# 定義

一年で最も暖かい月の月平均気温。

- 期間: 1990–2019 年の平年値
- 範囲: 都市圏ポリゴン内の ERA5 陸セル（陸海マスク ≥ 0.5）の平均。セルがなければ最寄りの陸セル
- 算出: 00/06/12/18 UTC の 2 m 気温を 30 年平均した月平均の最大値。ERA5 の地形高度と都市の平均標高の差を 6.5 K/km で補正

# スコアへの入り方

理想値型。ユーザーの理想値との差をガウス関数で 0〜1 にする（変換 `linear`、σ = 3）。

# 根拠と検証

許容幅 σ = 3 ℃ は「夏の体感がはっきり変わる差」として設定した設計値。観測所（GHCN-M v4、248 都市圏）との比較で、標高補正後の誤差は RMSE 0.59 K。

# 注意点

都市熱島を含まない（観測所より平均 0.3 K 低い）。標高補正が 0.5 K を超える都市は推定扱い。
