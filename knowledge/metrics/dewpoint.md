# 定義

月平均の 2 m 露点温度が最も高い月の値。蒸し暑さの指標。

- 期間: 1990–2019 年の平年値
- 範囲: 最暖月と同じ
- 算出: 00/06/12/18 UTC の 2 m 露点温度の月平均（30 年）の最大値。標高補正なし

# スコアへの入り方

理想値型。ユーザーの理想値との差をガウス関数で 0〜1 にする（変換 `linear`、σ = 3）。

# 根拠と検証

最暖月の露点ではなく最も蒸す月の値を使う。モンスーン・高地の都市では最暖月が雨季より前に来るため、最暖月の値では 3〜4 K 過小になる（デリー、ボゴタ、メキシコシティ、アディスアベバ）。許容幅 σ = 3 ℃。

# 注意点

露点は湿度そのものではなく、空気中の水蒸気量の指標。おおむね 16 ℃ を超えると蒸し暑く感じやすいとされる。
